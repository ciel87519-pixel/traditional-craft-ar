うつわ日和 AR版（iPhone対応）

【ファイル構成】
index.html
models/plate.glb
models/cup.glb

【重要】
iPhoneの「ファイル」アプリでHTMLを直接プレビューする方法では、ARは動作しません。
このフォルダの中身を、HTTPSに対応したWebサーバーへフォルダ構成を保ったままアップロードしてください。
アップロード後に発行される https:// から始まるURLを、iPhoneのSafariで開いてください。

【操作】
1. 皿／コップを選択
2. 3Dモデルを指で回転・拡大して確認
3. 「ARで空間に配置する」を押す
4. iPhoneのAR表示に従って、床やテーブルなどに配置

【注意】
・インターネット接続が必要です（model-viewerの読み込みに使用）。
・iPhoneのSafariとARKit対応端末で利用してください。
・AR起動可否は端末・iOS・ブラウザの対応状況に依存します。
・価格、説明、サイズ、産地等は「EC写真版_2_now.html」の内容に合わせています。
